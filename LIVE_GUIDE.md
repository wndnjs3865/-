## Pre-Flight Checklist / 사전 점검

Before going live, verify ALL of the following:

| # | Check | Command/Action |
|---|-------|---------------|
| 1 | Exchange API keys configured | Edit `.env`: `BINANCE_API_KEY`, `BINANCE_API_SECRET` |
| 2 | Risk parameters reviewed | `MAX_RISK_PER_TRADE=0.01`, `MAX_DAILY_LOSS=0.03` |
| 3 | Circuit breaker enabled | `CIRCUIT_BREAKER_LOSS=0.05` (5%) |
| 4 | System runs in PAPER mode for 24h+ | `TRADE_MODE=PAPER` |
| 5 | All 115 tests pass | `python -m pytest tests/ -v` |
| 6 | Telegram alerts configured (optional) | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |

## Step-by-Step Activation / 단계별 활성화

### Step 1: Deploy / 배포

```bash
# Option A: Docker
docker compose up -d

# Option B: Direct
pip install -r requirements.txt
python main.py

# Option C: Railway
# Push to GitHub → Railway auto-deploys
```

### Step 2: Observe in PAPER Mode / PAPER 모드 관찰

Run in PAPER mode for **minimum 24-48 hours**. Monitor:
- Signals generated by MIA
- QR scores distribution
- CRCO approval/veto ratio
- ES execution accuracy
- PO performance metrics

### Step 3: Run Safety Gate / 안전 게이트 실행

```python
# Via API or Python console:
result = await system.validate_live_readiness()
print(result)
# Must show: {"passed": True, "gates": [...], "blockers": []}
```

The 3-stage safety gate checks:
- **Gate 1**: API keys present, risk params sane
- **Gate 2**: No circuit breaker, no open positions, no daily loss
- **Gate 3**: Conservative risk limits enforced

### Step 4: Switch to LIVE / LIVE 전환

```python
result = await system.switch_mode("LIVE")
# If safety gate fails, auto-reverts to PAPER
```

**THIS IS THE POINT OF NO RETURN — REAL MONEY AT RISK**

### Step 5: Monitor / 모니터링

```python
# System status
snap = system.system_snapshot

# Risk status
risk = system.crco.risk_snapshot

# Open positions
trades = system.es.open_trades

# Performance
report = system.po.generate_report("daily")
```

## Emergency Procedures / 긴급 절차

### Emergency Stop / 긴급 정지

```python
await system.emergency_stop()
```

This will:
1. Close ALL open positions immediately
2. Activate circuit breaker (blocks new trades)
3. Log everything to audit trail
4. Fire FATAL alert to IMA/Telegram

### Revert to PAPER / PAPER 복귀

```python
await system.switch_mode("PAPER")
# Always allowed, no gate required
```

### Manual Circuit Breaker / 수동 서킷브레이커

```python
system.crco.set_circuit_breaker(True)   # Activate
system.crco.set_circuit_breaker(False)  # Deactivate
```
